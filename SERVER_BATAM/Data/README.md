# 📊 KiBot Data & State

Persistent storage, state files, and testing sandbox.

## Responsibility
- **State Management**: JSON files tracking equity, PnL, and system health.
- **Raw Data**: Intelligence bundles and learning states.
- **Testing**: `Tests/` and `Scratch/` for experimental development.

## Subdirectories
- `State/`: Live runtime status and portfolio data.
- `Raw_Data/`: Bundles and static intelligence data.
- `Tests/`: Unit and integration tests.
- `Scratch/`: Debugging and temporary scripts.
