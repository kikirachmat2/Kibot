# 🔓 KiBot Infrastructure: AI Vault & Model Management

Inventory and configuration of local AI models used within the Trinity Cluster.

## Responsibility
- **Model Tracking**: Maintaining a manifest of all local models (Ollama, Dify).
- **Version Control**: Tracking which model versions are currently active for the Trading Council and Brain.
- **AI Inventory**: Detailed documentation of model capabilities and performance targets.

## Key Files
- `AI_MANIFEST.md`: A comprehensive document listing every local model, its role (e.g., Reasoning, Veto, Scouter), and its deployment status.
