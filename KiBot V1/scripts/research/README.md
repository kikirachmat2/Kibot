# 📊 scripts/research — Skrip Eksperimen & Analisis Kuantitatif

Folder ini berisi skrip analitis yang digunakan untuk riset kuantitatif, kalibrasi performa backtesting, dan evaluasi sinyal ground-truth.

---

## 📁 Daftar Skrip & Fungsinya

| Skrip | Penjelasan Fungsi (Bahasa Awam) |
| :--- | :--- |
| [`validate_backtest_calibration.py`](./validate_backtest_calibration.py) | **Kalibrator Backtest**: Memvalidasi akurasi perhitungan simulator backtesting terhadap pergerakan harga pasar riil. |
| [`expand_ground_truth_investigation.py`](./expand_ground_truth_investigation.py) | **Investigasi Sinyal Riil**: Menganalisis seberapa akurat sinyal yang dihasilkan oleh Scanner ketika dicocokkan dengan data harga aktual yang terjadi di bursa. |
