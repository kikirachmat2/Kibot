# 🏗️ KiBot Infrastructure

Systemd services, Deployment scripts, SSH keys, and Automation.

## Responsibility
- **System Control**: Management of Linux systemd units.
- **Deployment**: Synchronizing code across the Trinity Mesh.
- **Security**: SSH keys and secure communication protocols.
- **Self-Healing**: Monitoring and auto-restarting failed components.

## Subdirectories
- `Infra/`: Core deployment and cluster control scripts.
- `Automation/`: Self-healing monitors and auto-deployment tools.
- `SSH/`: Secure keys for mesh communication.
- `systemd/`: Unit files for all KiBot services.
