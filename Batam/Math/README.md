# 🔢 KiBot Math & Indicators

Statistics, Sentiment Analysis, and Market Indicators.

## Responsibility
- **Stats Engine**: High-performance statistical calculations.
- **Sentiment**: Analysis of order book imbalance and market mood.
- **Indicators**: Moving averages, volatility, and trend detection.

## Key Files
- `ki_stats.py`: Core math library.
- `ki_sentiment_engine.py`: OBI and sentiment processing.
- `coin_universe_overlay.py`: Cross-pair correlation.
- `kibot_timeframe_analyzer.py`: Multi-timeframe trend detection.
